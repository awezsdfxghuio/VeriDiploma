# VeriDiploma: Децентрализованная система академической верификации на Soulbound-токенах (SBT)

**VeriDiploma** — децентрализованный Web3-сервис для выпуска, верификации и аннулирования академических дипломов и квалификационных сертификатов. Проект исключает возможность подделки документов об образовании и устраняет посредников при проверке подлинности со стороны работодателей (HR).

---

## Архитектура и ключевые особенности

* **Soulbound Tokens (ERC-721 SBT):** Все попытки передачи (`transferFrom`, `safeTransferFrom`, `approve`) аппаратно заблокированы на уровне смарт-контракта кастомной ошибкой `DiplomaIsSoulbound()`. Токен неделимо привязан к адресу кошелька выпускника.
* **OpenZeppelin AccessControl (Двухэтапная валидация):**
  * `DEAN_ROLE` (Деканат): формирование проекта приказа о выпуске диплома (`proposeDiploma`).
  * `RECTOR_ROLE` (Ректорат): утверждение и чеканка токена студенту (`approveDiploma`), а также право отзыва (`revokeDiploma`).
* **100% On-Chain Metadata & Dynamic SVG:** Изображение диплома генерируется смарт-контрактом в виде векторного SVG и кодируется в Base64 Data URI прямо в блокчейне. Отсутствует зависимость от внешних хранилищ данных (IPFS, AWS S3).
* **Динамический штамп аннулирования:** При отзыве диплома статус переходит в `Revoked`, а контракт автоматически накладывает на генерируемый SVG-бланк штамп с основанием отзыва.
* **Изолированный доступ:** Публичный портал верификации (`/`) работает в режиме чтения без обязательного подключения Web3-кошелька. Служебный шлюз университета вынесен на закрытый маршрут (`/admin`).

## Технологический стек

* **Блокчейн / Смарт-контракты:** Solidity (v0.8.24), Hardhat, OpenZeppelin Contracts (AccessControl, ERC721).
* **Бэкенд-индексатор:** Python 3.11+, FastAPI, Web3.py, SQLite, Uvicorn.
* **Фронтенд:** React, Vite, Tailwind CSS, Ethers.js v6, React Router DOM.
* **Провайдер авторизации:** MetaMask.

## Пошаговый запуск и воспроизведение

### 1. Запуск локального блокчейна и развертывание контракта

Терминал 1 (корень проекта):

```powershell
cd D:\VeriDiploma
npx hardhat node
```

*Скопируй приватные ключи аккаунтов `Account #1` (Декан) и `Account #2` (Ректор).*

Терминал 2 (корень проекта):

```powershell
cd D:\VeriDiploma
npx hardhat run scripts/deploy.js --network localhost
```

---

### 2. Запуск бэкенда (Индексатор)

Терминал 3:

```powershell
cd D:\VeriDiploma\backend
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn main:app --reload --port 8000
```

*Документация REST API доступна по адресу `http://localhost:8000/docs`.*

---

### 3. Запуск фронтенд-приложения

Терминал 4:

```powershell
cd D:\VeriDiploma\frontend
npm install
npm run dev
```

Приложение будет запущено по адресу `http://localhost:5173/`.

## Жизненный цикл диплома (Тестовый сценарий)

1. **Создание проекта (Деканат):**
   * Перейди на `http://localhost:5173/admin` и подключи кошелек **Декана**.
   * Во вкладке **Кабинет Деканата** заполни форму (адрес студента, ФИО, направление) $\to$ нажми «Сформировать приказ».
2. **Утверждение (Ректорат):**
   * В MetaMask переключись на **Ректора**.
   * Во вкладке **Кабинет Ректората** диплом отобразится в блоке «Очередь на подписание». Нажми «Утвердить в 1 клик» и подтверди транзакцию.
3. **Публичная проверка (HR / Работодатель):**
   * Перейди на главную страницу `http://localhost:5173/` (MetaMask можно отключить).
   * Введи ID диплома $\to$ получи статус **Active** и сгенерированный векторный бланк из блокчейна.
4. **Аннулирование (Ректорат):**
   * В кабинете Ректората укажи ID диплома, причину аннулирования и нажми «Отозвать диплом».
   * Повторная проверка покажет статус **Revoked** с наложенным штампом об отзыве.
